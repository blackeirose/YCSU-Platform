- Browser and native Computer Use connections timed out during this closeout. No fresh agent-operated DevTools network/console capture, browser storage inspection or responsive screenshot is claimed. Current production interaction is the user's explicit confirmation; current DOM/request checks use JSDOM plus real HTTP. Previously accepted real desktop/mobile, 1440/820/390 layouts, console, session and browser DOM checks remain applicable because all JavaScript/HTML/CSS bytes are unchanged. See [v1.3](v1.3.0.md) and [v1.4](v1.4.0.md).
- Production now has 11 active records. The deliberately manual public-safe fallback contains eight older records. If the backend is unavailable it can show fewer public cards, but never owner URLs or offline owner access. Refreshing that content and creating new curated previews are separate maintenance tasks, not required security fixes.
- This feature protects MAIN's current Registry delivery and clickable UI, not secrecy of historically published domains or access control of downstream applications. Historical Git/deployments and public architectural documents may retain domains. Previously received owner data, copied URLs and already opened destination tabs cannot be recalled by logout. Downstream apps must enforce their own authorization.

All six close criteria pass on this evidence: owner access, unauthorized link denial, protected-data denial, reliable logout, verified production identity/behavior, and no major regression. Keep the existing secure-read recovery boundary; never restore browser raw-table grants, a full public snapshot or repository-root deployment.
