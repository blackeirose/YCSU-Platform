# YCSU Platform v1.2.0 — Persistent Product Card Reordering

Product cards can now be reordered by the existing authenticated owner, with the order saved in the live Registry and retained on reload without redeployment. Public browsing remains available. Drag the grip directly with a mouse, or hold a non-link card area / touch grip for 500 ms; keyboard Arrow/Home/End controls provide an alternative.

- Added nullable integer sort_order, original-order backfill and transactional stale-state protection.
- Reused registry-ops for owner-only reorder; management CRUD still requires its existing secret.
- Preserved product metadata, link behavior, preview design and responsive layout.
- Failed saves restore the previous order; pointer cancellation and final-drop timing are covered by regressions.
- Production owner mouse drag → save → reload → restore passed, with no console errors or metadata changes. YuCheng confirmed real-device drag/touch working on 2026-09-11. Eight regression cases and independent review passed.

This release contains only persistent ordering and its fixes. Owner-only product-link access belongs to v1.3.0 and is not included here.
