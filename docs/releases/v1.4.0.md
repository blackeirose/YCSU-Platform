**Status: mobile acceptance passed; final release checks in progress.** Released baseline remains v1.3.0 until publication. Branch: feat/mobile-email-otp.

## Scope and implementation

Mobile Magic Links may open Gmail/Mail's embedded browser or another browser context, so the original MAIN browser does not acquire that session. The candidate lets users enter an emailed six-digit code in the browser where they started. It uses the existing Supabase Auth SDK and exact server-side owner UUID authorization. No Registry architecture, permission or other-app changes.

Request: signInWithOtp, shouldCreateUser:false, explicit MAIN emailRedirectTo. Verify: verifyOtp with email/token/type=email. One field supports leading zeroes, numeric keypad, one-time-code autofill, paste and Enter. Resend uses a 60-second cooldown. Safe errors cover invalid/expired/used codes, network failure, rate limits and non-owner sessions. Standard SDK persistence and Magic Link callback support remain. Old verification results cannot resurrect a superseded session.
